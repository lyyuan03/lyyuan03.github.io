# 靈元院｜116 年丁未歲點燈報名系統

## 狀態
此為可部署版本，**未經 Apps Script 擁有者授權部署、程式碼審查及實際驗收前，不接受真實個資／正式訂單。**

- 官網 `niandian.html` 顯示 116 年燈別、價格、太歲生肖及試算。
- `lamp-116/Index.html`：Apps Script 報名網頁。Email 驗證後可存取自己的名單。
- `lamp-116/Code.gs`：Apps Script 後端；向私有 Google 試算表寫入聯絡人、家人、訂單及明細，並寄送回函。
- `lamp-116/config.js`：正式 Web App 網址。未部署時維持空白，官網只顯示試算、不可提交。

## 使用的 Google 帳號
請在 `lyyuan03@gmail.com` 登入 Google Apps Script，並在該帳號私有的點燈試算表中操作。**不要在 GitHub 放入真實信眾資料、密碼、驗證碼、OAuth token 或金鑰。**

## 部署步驟（必須由 Google 帳號持有人完成）

1. 在 `https://script.google.com/` 使用靈元院帳號建立新 Apps Script 專案。
2. 將 `Code.gs`、`Index.html` 複製進 Apps Script，同名檔案建立完成。
3. 打開 Apps Script「專案設定 → 指令碼屬性」，新增 `LAMP_SPREADSHEET_ID`，值為剛建立的 116 年點燈 Google 試算表 ID。**不要提交到 GitHub。**
4. 在 Apps Script 編輯器手動執行 `setupLampSystem()` 一次，檢視 Google 要求的試算表、寄信等權限，確認後授權。
5. 先以**虛構**姓名與 Email 測試；驗證失敗五次、驗證碼逾期、未授權查看家人、錯誤金額等都要測試。
6. 由靈元院帳號部署「網頁應用程式」。執行身分選「我」，存取權限選「任何人」，取得結尾為 `/exec` 的正式網址。因為使用者無需 Google 帳號，務必先確認驗證碼與權限隔離皆正常。
7. 當回函、訂單寫入和權限測試全數通過後，在私有試算表的「燈別設定」將準備開放的三種**個人燈**狀態由「建置中」改為「開放」；其他總燈首和公司行號燈仍需人工處理。
8. 最後在 GitHub `lamp-116/config.js` 設定 `window.LYYUAN_LAMP_WEBAPP_URL` 為部署取得的正式 /exec 網址，經 PR 審核、檢查通過並合併後，官網才開始顯示真正的報名介面。

## 個資保護及上線前驗收
- Google 試算表權限設為「限制存取」，不可分享給「知道連結的任何人」。
- 前台頁面不直接讀寫 Google 試算表；每個操作都由 Apps Script 按照 Email 驗證後的 session 查核。
- 確認系統在多次錯誤驗證碼、異常重複送單、手機與不同瀏覽器的行為。
- Email 回函不包含生辰，姓名部分遮蔽，並清楚註明待匯款。
- 不可將 Apps Script Web App 網址誤認為機密：網址可以公開，安全性依靠後端驗證與存取管制。
- 高強度防濫用、完整個資刪除介面、異常存取警示、匯出權限及稽核必須在正式上線前依管理需求補齊並測試。
- 如果想保留 116 年既有公告而不立即開放新登記，保持 `config.js` 空白即可。
