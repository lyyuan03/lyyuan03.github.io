# 點燈報名後台（Phase 2＋3）

後台是**另一個** Google Apps Script 網頁應用程式（獨立部署，與公開報名端點分開），由管理者本人的 Google 帳號登入；
網址、帳號白名單與匯款資料**不放在本 repo**（程式碼也不在此 repo，只存在 Apps Script 專案與管理者的備份）。

## 安全設計

- 後端以「使用存取者身分」執行（`executeAs: USER_ACCESSING`），並在 `doGet` 與每一個 `api_*` 函式都檢查 `Session.getActiveUser().getEmail()` 是否為管理者本人；非本人只會看到拒絕頁，任何資料都不會回傳。
- 訪客需自己對試算表有權限，等於再加一層。
- 公開端點（`?action=config` 等）永遠不含匯款帳號、確認信文案、私密分頁名。

## 功能

1. 報名總覽：筆數、各燈別／商品數量與金額、篩選、管理者註記（只改該欄）。
2. Excel 下載：完整版與簡版（同一份資料產生，欄位同步）。
3. 內容編輯：所有設定欄位，儲存前驗證、顯示變更清單；每次儲存留版本，可回復（回復會產生新版本）。
4. 狀態：開放／關閉／草稿。
5. 已有人報名的燈別／商品只能停用，不能刪除（有警告）。
6. 重建報名總表：僅在欄位順序需整理時使用，須先關閉活動，自動備份。
7. 動態活動：頁面 `?event=` 參數，見 signup-event-config.md。
8. 活動管理（Phase 3）：切換活動、每個活動的公開報名網址（含複製鈕）、複製為新活動（名稱／代碼可留空自動產生，草稿起跳）、草稿預覽網址（含預覽碼，只在後台顯示，可重新產生）。
