# 2027 丁未年十二生肖：共用文章閱讀系統（屬鼠範本）

> 本文件只說明版型、元件與權限稽核結果，不含任何文章正文。
> 文章內容以 ChatGPT Work 查證、作者核定的原稿為準；版型不增刪、不改寫任何文字。

| `zodiac-article.css` | **本次新增**：字級與留白尺度、文字欄寬、公開／專屬分界、專屬正文版面、引言、節氣時間軸、年度總結、側邊目錄、生肖切換 |

## 二、版型尺度（全部生肖共用）

- 文字欄：正文字級 × 35（桌面約 630px），每行約 33～35 個全形字；主視覺保留整個面板寬度。
- 正文：桌面 18px／行高 2.0；手機 16px／行高 1.98；段距 1.3em。
- H1 32～46px；H2 22～28px（字重 500，金色點線在上）；H3 18～20px。
- 大段落間距 72px（手機 56px），小節 40px（手機 32px）。
- 標題只在標點處換行，避免拆開詞語；錨點預留 128px（手機 112px），不被固定導覽列遮住。
- 目錄：1360px 以上固定在左側；以下為可折疊目錄，手機選取章節後自動收合。

## 三、專屬全文的原稿格式（管理頁貼上的純文字）

管理頁不接受 HTML。只用以下標記，版面自動套用，**文字不做任何修改**：

```text
空一行 → 分段
## 章節標題
### 小節標題
> 引言（只標記原稿中作者或審稿者選定要強調的句子）
```

- 章節標題含「流月」「節氣」「月令」時，其下每個 `###` 小節成為節氣時間軸的一個月份，並自動產生月份導覽；月份順序、數量、文字完全依原稿。
- 章節標題含「年度總結」「結語」「修行建議」時，以總結版面呈現。
- 沒有這些標記的舊格式純文字，照原本方式逐段顯示。

## 四、套用到其他十一生肖的步驟（待屬鼠範本確認後執行）

1. 各頁 `<head>` 加入 `zodiac-motion.css`、`zodiac-article.css`；`</body>` 前加入 `zodiac-motion.js`。
2. 在 `<section class="zp-lamp" …>` 前加入分界：`<div class="zr-divide" role="separator" …><span>年度點燈專屬全文</span></div>`。
3. 以 `.zr-switch`（上一生肖／十二生肖總覽／下一生肖）取代 `.zp-nav`，放在生肖選擇區之前；上一、下一生肖依十二生肖循環（鼠的上一個是豬）。
4. 公開篇的 HTML 文字不動。
5. 執行 `python3 scripts/tests/zodiac-reader-states.py`（改 PAGE 參數逐頁跑）與下列審查腳本。

## 五、權限稽核結果（2026-11-15）

### 已確認

- 公開 HTML、JavaScript、JSON、Markdown 與 Git 歷史中，沒有找到任何生肖專屬正文。
- 未登入時不向資料庫讀取正文；未授權、其他生肖、網路錯誤等狀態下，頁面 DOM 與目錄都不含任何專屬文字；登出後已載入的正文與目錄標題一併移除。
- 專屬正文一律先跳脫再排版，原稿中的 HTML 只會以文字顯示。
- `eventArticleBodies` 不開放列出；非管理員必須同時符合：外殼已發布、正文已發布且開放、帳號為已驗證 Gmail、權限文件含該生肖權限、帳號未停用。
- 對非管理員，「文件不存在」與「沒有權限」同樣回傳拒絕，前端刻意不區分，避免透露哪些生肖已建立正文。

### 建議強化（尚未修改 `firestore.rules`，需宇色老師確認）

1. `isAdmin()` 未檢查 `email_verified`。Google 登入的信箱一定已驗證，但若日後啟用其他登入方式，可能被未驗證的同名信箱冒用。建議：
   ```
   function isAdmin() {
     return signedIn() && request.auth.token.email_verified == true
       && request.auth.token.email in ["lyyuan03@gmail.com"];
   }
   ```
2. `eventArticleBodies` 的讀取條件沒有把 `requiredPermission` 綁定到文件 ID。管理頁寫入時兩者一定相同，但若有人手動改錯，持有其他生肖權限者可能讀到這篇。前端已會拒絕顯示，但資料已下載到瀏覽器。建議在讀取條件加上 `&& resource.data.requiredPermission == articleId`。

模擬器測試 `scripts/tests/dingwei-zodiac-rules.test.mjs` 已加入這兩項「稽核觀察」（NOTE，不影響通過與否）及十二生肖逐一的管理員／未授權／未登入測試。

## 六、文字待審清單（只列出，不修改；交 ChatGPT Work 查證、作者核定）

屬鼠公開篇：

1. 正文「2027年，屬鼠者……」數字與「年」相連；頁首「2027 丁未年」數字後有空格。全站寫法是否統一？
2. 「古籍與流年說法」段：「月德有扶助的吉德意象，但不同排法不能混用」——「但」前後的語意關係不夠清楚，讀者可能不明白「不同排法」指月德的哪一種起例。
3. 同段「曆書另見死符、小耗等名目，常涉及行事宜忌與耗損」——「曆書」是否需註明出處或版本，與《術語事實表》一致？
4. 「年煞的具體主事仍待考證」是事實表的待核對用語，是否適合直接出現在公開頁，請作者決定。
5. 頁尾說明「各家起例可能不同；生活與心性討論供自我觀察，不能推斷個人的疾病、財富或命運」——與總覽頁說明文字略有不同，是否統一。
