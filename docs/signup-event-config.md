# 點燈報名頁：活動內容設定（Phase 1＋2＋3）

報名頁（`preview-vokdayja/`）的「每個活動會變的內容」都放在一份設定裡，不再寫死在程式。

- **內建預設**：`preview-vokdayja/config.default.js`（`window.LYYUAN_SIGNUP_DEFAULT_CONFIG`）。頁面先用它立即渲染；Google 連不上時頁面照常運作。
- **雲端設定**：Google 試算表「活動內容設定」分頁，每個活動一列（活動代碼、版本、最後更新、更新者、設定 JSON）。Apps Script 以
  `GET ?action=config&event=<活動代碼>` 公開提供（快取 120 秒），頁面每次載入只抓一次；內容與內建預設相同就不重繪，不同才重繪並保留已填資料。
- **私密設定**（匯款帳號、確認信文案、報名總表分頁名、報名頁網址）存在隱藏分頁「_私密設定」，只有伺服器讀取，**不會**經過 config 端點，也不在此 repo。
- 伺服器端金額（燈種單價、商品單價與限購、贊助固定金額、運費門檻）一律以設定計算，不信任瀏覽器送來的數字。

## 設定結構（schema 1）

`meta`（頁名、頁面標題、年度標籤、`deadline` 截止時間，台北時間，空白＝不限）、`shipping`（`freeThreshold`、`fee`）、`families`（燈別分頁）、
`roleOrder`／`roleLabels`、`lamps`（key、family、name、role＝個人／公司／總燈首、price、purpose、fortune 籤詩、gift 特贈、hot 熱門、enabled）、
`sponsors`（key、title、fixed；0＝隨喜）、`products`（id、name、price、limit、photo、detail）、`zodiac`（犯太歲卡片與統計）、`stats`（門檻、熱門數）、
`agreements`（注意事項標題與內文）、`copy`（燈卡與統計文字）、`page`（頁面各區標題／說明）、`images`（四張主圖的路徑與說明）。

文字可用 `{{freeThreshold}}`、`{{shippingFee}}`、`{{limit}}`、`{{deadline}}` 代入數字；籤詩／特贈／說明只允許 `<strong>`、`<br>`、`<b>`，其餘會被轉義。

## 尚未可設定

版面與樣式、登記人資料欄位（標籤與提示字）、導覽列與頁尾、送出結果視窗、運費試算訊息、示意用管理面板、圖片檔本身（只能改路徑與說明）。

## 多活動：`?event=`（Phase 2）

同一個頁面可服務多個活動：網址加上 `?event=<活動代碼>`（小寫英數與連字號，3–61 字元）即讀取該活動的設定與報名總表；沒有參數＝預設活動 `lamp-116-dingwei`，外觀與行為與以前完全相同。
活動狀態來自「活動設定」分頁：**開放**（正常）、**關閉**（頁面顯示「本次報名目前已關閉」，伺服器拒收新報名與確認信修改連結）、**草稿**（公開端點只回傳狀態，不回傳內容，頁面顯示「尚未開放報名」）。
設定有更動後，公開頁面最久約 2 分鐘（伺服器快取）才會反映。

### 載入閘（非預設活動不閃現預設內容）

`index.html` `<head>` 內有一小段同步腳本：若 `?event=` 是有效的非預設活動，就先把 `<html data-ev="pending">`，樣式（`style.css` 末段）隱藏頁面並顯示「載入中」。`app.js` 取得該活動設定後移除閘；活動不存在／草稿／讀取失敗則改為 `data-ev="unavailable"` 並顯示訊息。預設活動不經過閘，行為與以前完全相同；整個機制只有 CSS 與事件，沒有計時器或 MutationObserver。

### 草稿預覽（只給管理者）

草稿活動的公開端點只回傳「尚未開放」。管理者可在後台取得預覽網址：`?event=<代碼>&preview=<預覽碼>`。預覽碼存在私密設定，只在後台顯示（可重新產生，舊碼立即失效）。預覽僅供檢視內容（頁面標示「預覽模式」且不可送出）；送出、統計、修改連結對草稿一律拒絕。預覽回應不進快取。

### 截止日（倒數）

`meta.deadline`（`YYYY-MM-DD` 或 `YYYY-MM-DDTHH:mm`，台北時間；空白＝無截止）。`deadline.js` 讀取目前活動的 `meta.deadline`：預設活動 lamp-116-dingwei 內建為 `2027-02-10T23:59`（顯示與先前一致）；其他活動讀取各自設定；沒有截止日就隱藏倒數。伺服器端也依同一個 `meta.deadline` 拒收逾期報名。

### 複製活動

後台「活動管理」可把一個活動複製為新活動（新代碼、新的明細與總表分頁，活動內容與私密設定一併複製，狀態＝草稿）。新活動的報名編號前綴與預覽碼各自獨立，報名確認信的修改連結帶有該活動的 `?event=`。

後台管理見 [signup-admin.md](signup-admin.md)。
